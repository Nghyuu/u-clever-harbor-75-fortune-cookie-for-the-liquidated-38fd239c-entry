One fortune cookie line for a crypto trader who was just liquidated, read at
3am with an empty wallet. It opens in the classic oracular cookie voice —
lucky numbers, as every good fortune promises — and then the numbers turn out
to be the trader's own undoing: the leverage they took, the margin call that
found them, and the balance left behind. The joke lands on the loss itself,
rueful rather than cruel, so the trader laughs with the cookie instead of
crying into it. `main.ts` (Node 22, stdlib only) writes the single line to
`<MAKEFUN_OUTPUT_DIR>/entry.txt`.
